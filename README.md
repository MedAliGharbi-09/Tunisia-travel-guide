# Tunisia Travel Guide

A small 4 page website about travelling in Tunisia. It is for first-time visitors who want to know where to go, what to eat and roughly what a trip costs. Built with HTML, CSS and JavaScript for the Unit 3 Web Development Project.

## Files
- index.html: Home page with highlights
- places.html: Places with a filter (beach, history, desert)
- food.html: Food and culture
- plan.html: Trip cost calculator and form with validation
- css/style.css: the one stylesheet used by every page
- js/script.js: the JavaScript functions
- images/: pictures used on the site (add your own photos here)

## JavaScript features
- Mouse events: button click (home), card hover (all pages), filter buttons (places)
- Trip cost calculator (plan page)
- Form validation: presence, length and range checks

## How to open
Download or clone this repository, then open index.html in a web browser.
